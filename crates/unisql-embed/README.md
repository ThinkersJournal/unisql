# unisql-embed

The value UniSQL's compile-time macros expand to: a statement already translated for each named target, as
`&'static` data. No dependencies, `no_std`.

Part of [UniSQL](https://github.com/ThinkersJournal/unisql) (pronounced "unicycle"). Design:
`docs/MACROS.md`. Licensed under MIT OR Apache-2.0.
