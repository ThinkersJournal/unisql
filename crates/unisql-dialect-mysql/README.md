# unisql-dialect-mysql

MySQL and MariaDB reader and target for UniSQL, with its matrix files.

Internal: depend on the `unisql` crate, not on this one.

Part of [UniSQL](https://github.com/ThinkersJournal/unisql) (pronounced "unicycle"): write SQL in one
dialect, get it back in another. Licensed under MIT OR Apache-2.0.
